# Korean B1/B2 (≈ TOPIK II levels 3–4) — Roadmap

_Written 2026-09-23. Read this before touching `/intermediate/`._

## 1. Which standard?

B1–B2 corresponds to **TOPIK II levels 3 and 4** (3급 ≈ B1, 4급 ≈ B2; TOPIK II is scored /300,
level 3 = 120+, level 4 = 150+) and to **grades 3–4** of the NIKL International Standard Curriculum
for Korean (국제 통용 한국어 교육과정) — the stage university language institutes teach as 3급–4급.
As with the beginner tier, lessons carry CEFR labels for parity with the sibling courses and a
"≈ TOPIK n" meta line.

What changes at this stage (NIKL grade 3–4 descriptors, condensed): handle **public-facility and
workplace** situations, talk about **social topics** in paragraph-length speech, read **news and
written-style texts**, follow **indirect/reported** information, and use **nuance endings,
passive/causative verbs and written style (한다체)** — TOPIK II's writing paper requires 한다체 and a
structured 600–700-character opinion essay at question 54.

## 2. What the A1/A2 tier already closed

The beginner tier (28 lessons) already teaches several items many syllabi park at grade 3:
-고 있다, -아 보다, -(으)ㄴ 적이 있다, noun modifiers (-(으)ㄴ/-는/-(으)ㄹ), 보다/제일/만큼,
-(으)ㄹ 때 / -기 전에 / -(으)ㄴ 후에 / -(으)면서, -(으)려고 하다, -(으)ㄹ게요/-(으)ㄹ까요,
all seven irregular classes, and the basic honorific system (-(으)시-, 드시다, 계시다, 께서).
The B1/B2 tier therefore **does not re-teach** these; it builds on them (e.g. -던 is taught against
the -(으)ㄴ/-는 modifiers learners already know).

## 3. Lesson count — derived

Grade 3–4 grammar, grouped into genuine single arcs (each a one-sitting lesson):

| Arc | Lessons | Why it can't merge / split |
|---|---|---|
| 반말 & speech-style switching | 1 | Grade 3 requires producing 반말, not just recognising it; distinct from B2 humble speech |
| Reported speech | **2** | Full forms (-다고/-냐고/-자고/-(으)라고) and the spoken contractions (-대요/-래요/-재요/-냬요, 달라고/주라고) are two separate skills; one lesson would be ~4,000 words |
| Conjecture & inference | 1 | 것 같다 / -나 보다 / -(으)ㄹ지도 모르다 / -는 모양이다 / -(으)ㄹ 테니까 form one "how sure am I" scale |
| Sentence-final nuance endings | 1 | -네요/-군요/-잖아요/-거든요/-는데요/-지요/-(으)ㄹ걸요 — the grade-3 conversational core |
| Reason & cause (expanded) | 1 | -느라고, -는 바람에, 덕분에/탓에, -길래 each carry restrictions |
| Contrast & concession | 1 | -아도/-더라도, -는데도, -기는 하지만, -는 반면에, -는 대신에 |
| Time & sequence (expanded) | 1 | -자마자, -는 동안, -는 길에, -다가/-았다가, -고 나서, -(으)ㄴ 지 |
| Purpose, intention, decision | 1 | -도록, -게, -기 위해(서), -기로 하다, -(으)ㄹ까 하다, -(으)려던 참이다 |
| Nominalisation | 1 | -기, -음, -는 것, -는 데, -는 편이다 |
| Embedded questions & choice | 1 | -는지 (알다/모르다), -거나, -든지, 아무 N(이)나 |
| Auxiliary (helper) verbs | 1 | -아 버리다, -고 말다, -아 놓다/두다, -아 있다, -아지다, -아 가다/오다 |
| Passive | 1 | -이/히/리/기-, -아/어지다, -게 되다 — grade 4 |
| Causative | 1 | a separate verb set and meaning; merging with passive is the classic textbook overload |
| Retrospective -더- | 1 | -더라고요, -던, -았던, -더니, -았더니 — hardest grade-4 item, needs its own lesson |
| Hypotheticals & regret | 1 | -다면, -(으)ㄹ 텐데, -았더라면, -았으면 좋았을 텐데, -거든 |
| Degree & extent | 1 | -(으)ㄹ수록, -(으)ㄹ 정도로, -(으)ㄹ 뻔하다, -(으)ㄹ 만하다, -다시피, -기는커녕 |
| Respect at B2 | 1 | humble verbs (여쭙다, 뵙다, 모시다), 저희, 하십시오체 in use, 압존법, service-speech errors |
| **Grammar subtotal** | **19** | |
| Living in Korea (public facilities) | 1 | named NIKL grade-3 domain: bank, ARC, phone plan, housing contract, 주민센터 |
| Workplace Korean | 1 | titles, email, phone, meetings — grade 3–4 core |
| Reading written Korean (한다체, news, headlines) | 1 | recognition arc: 한다체 forms + nominal headline style |
| Opinion & argument (speaking + TOPIK 쓰기 54) | 1 | production arc; different skill from reading written style |
| Sino-Korean roots | 1 | ~60% of Korean vocabulary; the B2 vocabulary-growth engine |
| Idioms, proverbs, 사자성어 | 1 | grade 4 comprehension requirement |
| Korean in the wild: dialects, slang, 줄임말, Konglish | 1 | media comprehension |
| TOPIK II strategy (3–4급) | 1 | capstone |
| **Total** | **26** | B1 = 1–14, B2 = 15–26 |

Merges already made: -아지다 (state change) rides with the helper verbs; -게 되다 with the passive;
-고자 with purpose; headline nominal style with 한다체 reading. (26 again equals French B1/B2 by
coincidence: French spends its lessons on the subjunctive and Québécois, Korean on reported speech,
-더-, passive/causative and written style.)

## 5. Architecture

- Pages: `intermediate/korean_lesson_N.html` (numbered). Scripts absolute: `/site-nav.js`,
  `/audio.js`, `/intermediate/vocab-data.js`, `/intermediate/lesson-content.js`, `/learn.js`.
- Shared engines at the root (`/learn.js`, `/glossary.js`) are tier-aware: `/intermediate/` →
  namespace `korean-int-`, SRS key `korean-int-srs`, numbered lesson links. Not copied.
- Per-tier: `vocab-data.js` (titles + levels, **no slugs map**), `lesson-content.js`, `index.html`
  (must contain `.container` for the dashboard), `cando.js/.html` (key `korean-int-cando`),
  `cheatsheet.js/.html` (grammar recipes), `readings.js/.html`, `glossary.html`, `build_anki.py`
  → `korean_intermediate.apkg`, `add_footer_nav.py` (footer prev/next, like the root).
- `site-nav.js` is tier-aware: header links to this tier's glossary/can-do.

## 6. Conventions
Same as `/docs/a1-a2-roadmap.md` §6 (exercise format, spacing-insensitive answers, vocab as single
source, objectives/summary in lesson-content.js). B1/B2 additions: every lesson includes a Korean
**reading passage** (150–400 characters, 한다체 or 해요체 as fits) with comprehension blanks, and
explanations stay in English while examples get longer and more natural.
